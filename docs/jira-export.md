# Jira Export

## Epic 1 — Offers Consultation

### PSA-2 — View Offers

**User Story:**
As a visitor, I can see offers, so that I can access all internship and alternance offers.

### PSA-4 — View Offer Details

**User Story:**
As a student, I can see the details of an offer, so that I can read the description or apply.

### PSA-17 — Admin Offers List

**User Story:**
As an admin, I will be able to see the list of offers on the admin panel, so I can manage them.

---

## Epic 2 — Filtering and Searching

### PSA-10 — Search Offers

**User Story:**
As a student, I will be able to search for offers by name, so that I can find the offer I want.

### PSA-12 — Filter Offers

**User Story:**
As a student, I will be able to filter offers by city, technology, and contract type, so that I can find the offers I want.

### PSA-13 — Sort Offers

**User Story:**
As a student, I will be able to sort offers by date, so that I can see the oldest or newest offers first.

---

## Epic 3 — Favorites

### PSA-14 — View Favorite Offers

**User Story:**
As a student, I can see my favorite offers, so that I can go back to them whenever I want.

### PSA-5 — Add Offer to Favorites

**User Story:**
As a student, I can save the offers I like, so that I can easily go back to them.

### PSA-15 — Remove Offer from Favorites

**User Story:**
As a student, I can remove an offer from my favorites, so that I can keep only the offers I want.

---

## Epic 4 — Offers Management

### PSA-11 — Offers Management

This epic covers the management of offers by the administrator.

### PSA-7 — Add an Offer

**User Story:**
As an admin, I will be able to add a new offer, so that I can publish new internship or alternance opportunities.

### PSA-8 — Modify an Offer

**User Story:**
As an admin, I will be able to modify an existing offer, so that I can update or correct its details.

### PSA-9 — Delete an Offer

**User Story:**
As an admin, I will be able to delete an offer, so that I can remove spam or unwanted offers.

---

## Epic 5 — Applications

### PSA-18 — Submit an Application

**User Story:**
As a student, I will be able to submit an application for an offer, so that I can track my application.

### PSA-19 — Delete an Application

**User Story:**
As a student, I will be able to delete a submitted application, so that I can manage my applications.
